# LesPrak

Материалы учебной практики (РТУ МИРЭА, 5 семестр, осень 2026).

**Тема:** Разработка и обоснование архитектуры клиент-серверного приложения для стримингового сервиса.

**Прототип:** [SoulMe](https://github.com/XeliteL/SoulMe) — некоммерческий VOD-сервис аниме.

## Структура

- `docs/` — тексты отчёта по этапам, перевод, список источников
- `diagrams/` — диаграммы draw.io (BPMN, UML, ER)
