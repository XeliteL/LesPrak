# 2. Объектно-ориентированная реализация на языке Java

> Черновик. Код: `src/java/`. Сборка и тесты: `cd src/java && mvn package` (Maven встроен в IntelliJ IDEA), демонстрация: `java -jar target/realty-1.0.jar`, замеры: `java -cp target/classes realty.Bench`.

Реализация выполнена в IntelliJ IDEA на Java 21, проект собирается системой Maven, тесты написаны на JUnit 5. Сторонних библиотек основная программа не использует, данные в формате JSON читаются собственным разборщиком. Программа читает тот же файл исходных данных, что и процедурная реализация, а неизвестные коды статусов отклоняются при загрузке.

Класс `Main` выполняет те же действия, что и `main.py`: оценивает квартиру, подбирает объекты, проверяет сделку и рассчитывает комиссию за месяц. Результаты совпадают с процедурной реализацией до рубля. Для этого учтены различия языков: функция `round` в Python округляет половину до чётного, поэтому в Java используется `Math.rint`.

Написано 26 модульных тестов. Они повторяют тесты процедурной реализации, проверяют допустимость значений в конструкторах и добавление нового правила без изменения классов алгоритмов. Сквозной тест сверяет вывод программы с выводом процедурной реализации. Все тесты выполняются успешно при каждой сборке.
