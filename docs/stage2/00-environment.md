## 0.1. Состав инструментального окружения

Работа ведётся в ОС Arch Linux. Состав окружения, определённый заданием на практику, приведён в Таблице 1.1.

| Инструмент | Версия | Назначение |

| Python | 3.14.9 | процедурная реализация алгоритмов (этап 3) |
| OpenJDK | 27.0.1 | объектно-ориентированная реализация на Java (этап 4) |
| PyCharm (JetBrains) | через JetBrains Toolbox | интегрированная среда разработки (IDE) для Python |
| IntelliJ IDEA (JetBrains) | через JetBrains Toolbox | IDE для разработки на Java |
| VSCodium | 1.143 | редактор для текстов отчёта (Markdown) и диаграмм |

## 0.2. Организация работы с системой контроля версий

Материалы практики хранятся в приватном репозитории Git LesPrak на GitHub, его структура приведена в Таблице 1.2.

| Каталог | Содержимое |
|---|---|
| `docs/` | тексты отчёта в формате Markdown, по одному подкаталогу на этап |
| `diagrams/` | диаграммы в формате `.drawio` |
| `tools/` | вспомогательные скрипты, в том числе сборка отчёта из Markdown в DOCX |
| `src/` (с этапа 3) | исходный код: процедурная реализация на Python, ООП-реализация на Java, SQL-скрипты физической модели данных |

Текст отчёта хранится в Markdown, чтобы git показывал построчные изменения, а DOCX собирается из него скриптом.

Работа ведётся в основной ветке `main`. Сообщения коммитов пишутся на русском языке и начинаются с указания этапа практики, к которому относится изменение, например «Этап 2: список источников сокращён до 7». Коммиты отправляются на GitHub, что одновременно служит резервной копией материалов. Структура репозитория на GitHub показана на Рисунке 1.4, история коммитов — на Рисунке 1.5.
