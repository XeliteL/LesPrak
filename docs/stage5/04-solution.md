# 4. Описание проектного решения

Предлагается информационная система агентства недвижимости, которая автоматизирует операции продажи квартиры на вторичном рынке: ведение объектов, заявок покупателей и сделок, оценку рыночной стоимости квартиры по объектам-аналогам, подбор объектов под заявку покупателя, контроль комплектности документов и сроков сделки и расчёт комиссии агентства и вознаграждения агентов.

Решение включает модель бизнес-процесса в нотации BPMN 2.0, логическую и физическую модели данных (16 таблиц PostgreSQL с ограничениями целостности), четыре алгоритма с оценкой вычислительной сложности и две их реализации: процедурную на Python и объектно-ориентированную на Java. Реализации дают одинаковые результаты, что проверяется автоматически, и покрыты 50 модульными тестами, а модель данных — 18 тестами. Объектно-ориентированная реализация позволяет добавлять новые правила оценки, подбора, проверки сделки и расчёта комиссии без изменения существующих классов.
